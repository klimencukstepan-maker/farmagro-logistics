## 1. Схема склада-хаба (consolidation-wh) — SVG-стрелки

**Файл:** `index.html` (строки ~630–645)

**Проблема:** SVG-стрелки, соединяющие блоки поставщиков со складом-хабом, не попадали в нужные точки. `preserveAspectRatio="xMidYMid meet"` сохранял фиксированное соотношение сторон 400:200 независимо от фактических размеров контейнера, из-за чего координаты линий не совпадали с реальным позиционированием блоков.

**Исправления:**
- `preserveAspectRatio="xMidYMid meet"` → `preserveAspectRatio="none"` — SVG теперь растягивается ровно под размер контейнера, координаты viewBox мапятся 1:1
- Пересчитаны координаты всех стрелок:
  - **Левая** (Поставщик 1 → Склад): путь `M64 24 C64 70 130 80 195 95` (из левого верхнего угла плавной кривой к центру)
  - **Центральная** (Поставщик 2 → Склад): линия `x1=200 y1=20 x2=200 y2=90` (вертикально вниз)
  - **Правая** (Поставщик 3 → Склад): путь `M336 24 C336 70 270 80 205 95` (из правого верхнего угла к центру)
  - **Исходящая** (Склад → РФ): линия `x1=200 y1=115 x2=200 y2=185` (вертикально вниз к нижнему блоку)
- Стрелочные наконечники (`<polyline>`) пересчитаны под новые конечные точки

## 2. Схема транзита (transit-kz) — соединительные линии между точками маршрута

**Файл:** `css/style.min.css` (класс `.transit-kz__connector`)

**Проблема:** `margin-bottom: 32px` на соединительных элементах смещал линию соединения вниз относительно центров иконок точек маршрута (Китай → Казахстан → Россия). Из-за этого стрелки/линии «съезжали» вниз.

**Исправления:**
- Удалён `margin-bottom: 32px` из `.transit-kz__connector` — линия теперь центрируется по `align-items: center` в flex-контейнере, совпадая с центрами иконок
- Добавлен `margin-top: 2px` на `.transit-kz__connector-icon` для точной подстройки иконки двойной стрелки

## 3. Меню навигации (nav) — выравнивание и отступы

**Файлы:** `css/style.css`, `css/style.min.css`

**Проблема:** `gap: 32px` между 8 пунктами меню создавал избыточную ширину — на экранах 1024–1200px пункты не помещались, навигация «ломалась» или вылезала за пределы хедера.

**Исправления:**
- `.nav__list`: `gap: 32px` → `gap: 16px` (в обоих CSS-файлах)
- Добавлен медиа-запрос для экранов 1025–1200px:
  - `gap: 10px` между пунктами
  - `font-size: 0.82rem` для ссылок (было 0.9rem)
- Мобильная версия (≤768px) не изменилась — меню по-прежнему открывается как выезжающая панель
