Дата: 2026-07-28

## 1. Меню навигации — выравнивание текста по центру

**Файл:** `css/style.css` — класс `.nav__link`

**Проблема:** Пункты меню с длинными названиями («Транзит через Казахстан», «Склад в Казахстане») переносились на вторую строку, которая съезжала влево (text-align по умолчанию left).

**Исправление:** Добавлен `text-align: center` в `.nav__link`. Теперь при переносе на вторую строку текст центрируется.

---

## 2. Схема транзита (transit-kz) — бейдж налезал на текст

**Файл:** `css/style.css` — класс `.transit-kz__stop-label`

**Проблема:** Бейдж «Ключевой узел» позиционирован абсолютно (`position: absolute; right: 16px; top: 50%; transform: translateY(-50%)`). При длинном названии точки маршрута (например, «Казахстан / Киргизия») текст заходил под бейдж и перекрывался им.

**Исправление:** Добавлен `padding-right: 140px` в `.transit-kz__stop-label` — текст не заходит под абсолютно спозиционированный бейдж.

---

## 3. Схема склада-хаба (consolidation-wh) — SVG-стрелки и блоки наезжали друг на друга

**Файл:** `css/style.css` — класс `.consolidation-wh__diagram`

**Проблема:** Контейнер схемы имел `min-height: 360px` без фиксированного соотношения сторон. SVG со стрелками имел `viewBox="0 0 400 200"` с `preserveAspectRatio="none"`, из-за чего координаты стрелок искажались при несовпадении пропорций контейнера с 2:1. Стрелки не попадали в нужные точки, блоки наезжали друг на друга.

**Исправления:**
- `.consolidation-wh__diagram`: `min-height: 360px` → `aspect-ratio: 2 / 1` — контейнер теперь всегда имеет пропорцию 2:1, совпадающую с SVG viewBox. Стрелки мапятся корректно.
- Мобильная адаптация (≤900px): `aspect-ratio: auto; min-height: 300px` — на мобильных схема может быть произвольной высоты.

**Проблема:** В заголовке не хватало ключевого преимущества — «без посредников».

**Исправления:**
