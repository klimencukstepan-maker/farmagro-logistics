### ➕ Рекомендации по .htaccess

```apache
# Включить mod_rewrite
RewriteEngine On

# Редирект на https (если сертификат есть)
RewriteCond %{HTTPS} off
RewriteRule ^(.*)$ https://проф-логист.рф/$1 [R=301,L]

# Кэширование статики (1 год для изображений, 1 месяц для CSS/JS)
<FilesMatch "\.(ico|pdf|flv|jpg|jpeg|png|gif|webp|svg)$">
  Header set Cache-Control "max-age=31536000, public"
</FilesMatch>
<FilesMatch "\.(css|js)$">
  Header set Cache-Control "max-age=2592000, public"
</FilesMatch>

# Gzip сжатие
AddOutputFilterByType DEFLATE text/html text/plain text/xml text/css text/javascript application/javascript application/x-javascript

# Charset
AddDefaultCharset UTF-8
AddCharset UTF-8 .html .css .js .php

# 404 страница
ErrorDocument 404 /404.html
```

## 5. Технические ошибки

### ✅ Хорошо

- Код валидный HTML5
- Яндекс.Метрика установлена на обе страницы
- Счётчик настроен с webvisor, clickmap, trackLinks

- Адаптивность: медиа-запросы есть на 1024px, 768px, 480px
- Burger-меню для мобильных работает

### ❌ Проблемы

| # | Проблема | Приоритет |
|---|----------|-----------|
| 14 | **Google Fonts загружаются через CSS @import** на index.html (блокирующий рендеринг). На vagonmarket.html — через `<link preconnect>` (лучше) | **P2** |
| 15 | **CSS на vagonmarket.html — inline**, не кэшируется браузером при переходе с index.html | **P2** |
| 16 | **Нет 404.html** — пользователь, попавший на несуществующую страницу, увидит пустую или стандартную страницу сервера | **P2** |
| 17 | **Нет HSTS заголовков** и HTTPS-принуждения (зависит от сервера) | **P2** |
| 18 | **OG-image.svg** — хороший, но для соцсетей лучше PNG/JPG (1200×630px, < 300KB) | **P3** |

### ➕ Рекомендации по оптимизации скорости

1. Google Fonts: загружать через `<link rel="preconnect" href="https://fonts.googleapis.com">` + `<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>` в `<head>`, **не через CSS @import**
2. Вынести CSS vagonmarket.html в отдельный файл `css/vagonmarket.css` для кэширования
3. Минифицировать CSS и JS перед деплоем
4. Добавить `defer` на `<script src="js/script.js">`
5. Создать `404.html`
